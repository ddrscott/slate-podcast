## Conventions

- **Slug-routed slate pages live under `src/pages/[slate]/`.** The dynamic param is `slate` and resolves to the slate's `slug`.
- **API endpoints live under `src/pages/api/`.** They're Astro endpoints (`export const POST: APIRoute = ...`), not edge functions. Each ends with `export const prerender = false`.
- **`@/...` import alias resolves to `src/`** (`tsconfig.json` paths).
- **All DB IDs are random hex strings** generated by `randomId()` in `src/lib/db.ts`. Slate IDs are prefixed `slt_`, slot `slt_` / activity `act_` / etc.
- **All timestamps are unix seconds (UTC) integers** in the DB. UI converts to `slates.timezone` on render.
